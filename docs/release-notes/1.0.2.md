Grably 1.0.2 brings the Strategies Beyond Limits colours, and asks before switching to a different copy of Grably.

## What's new

- **New colours:**
  - buttons and toggles are navy (a lighter navy in the dark theme)
  - selection outlines and handles, the crop box and the trim editor's selection are orange
  - the logo, app icon and tray icons are redrawn in navy and orange
  - in recordings, left clicks show an orange ring and right clicks a navy one, so red only ever means "recording"
- **Credit:** Settings ends with "Built By" and the Strategies Beyond Limits logo, which opens sbladvisory.com.
- **Another copy of Grably:** starting a different Grably.exe while one is running, for example a portable copy next to the installed one, now asks first. The question names both copies' versions and folders.
  - **Yes** closes the running copy and starts this one. If the running copy is recording, exporting or has unsaved changes, it asks you first, and cancelling there keeps it open.
  - **No** opens the copy that is already running.
  - Starting the same copy again opens it, as before.
  - Grably 1.0.0 cannot be closed this way: the question explains how to quit it from its tray icon.
- **Start with Windows** follows the copy you use. If another copy of Grably turned it on, the copy you start now takes it over, so the old copy no longer starts when you sign in. Uninstalling removes it only when it belongs to the uninstalled copy.

## Updating

An installed Grably 1.0.0 finds this update by itself, 30 seconds after it starts and every 12 hours after that, while **Check for updates automatically** is on in Settings (it is by default). **Check for updates** in Settings looks right away. Grably downloads the update in the background, then installs it when you choose **Restart to update** in the tray menu, or the next time Grably starts.

## Installing

Download `SBLAdvisory.Grably-win-Setup.exe` below and run it. Grably installs for your Windows account only, so no administrator rights are needed.

The installer is not code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Choose **More info**, then **Run anyway**.

Requires Windows 11, 64-bit.

## Good to know

- **Encoding:** recording uses your graphics card's video encoder (NVIDIA, AMD or Intel) when it has one, otherwise the encoder built into Windows.
- **Scrolling capture** works best on pages that scroll by whole lines. Browsers at 125 % scaling may stitch with small mismatches.
- **Very small text:** text capture reads small coloured button text (12 px) less reliably than other text.
